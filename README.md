# Restaurant

A simple website for an upcoming restaurant looking to reach new customers. The website is meant to orient new customers to the restaurant's culture while showcasing the services they offer. It also offers a means through which they can explore and discover what the restraurant offers and how to access it.

## Features

**An informative page** where users clients can learn more about the restaurant.
**Menu** where customers can explore what delicacies are offered under their roof
**Events** where customers can see events that are being hosted or planned by the restaurant.
**Location** where people can view all the locations where the restaurant has a branch.
**Contact form** through which clients can reach the staff for whichever reason
**Socials** through which the clients can be able to follow the restaurants social handles
